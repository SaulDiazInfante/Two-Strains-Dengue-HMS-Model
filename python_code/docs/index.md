# Package Documentation

This directory contains package-level documentation that complements the inline
docstrings in `src/StochasticSearchPy/`.

## Contents

- `api.md`: public Python API and CLI surface
- `workflows.md`: data preparation, local runs, and CI/TDD workflow
- `github-pages.md`: repository-level GitHub Actions and Pages setup

## Scope

The code-level docstrings are intended to support:

- IDE hover/help output
- `help(...)` / `pydoc`
- generated API references in future tooling

The Markdown files in this directory are intended to support:

- repository onboarding
- packaging and release work
- reproducible data preparation and execution
